# KWF CYOA Game
This Git includes all of the sources files for the Kashmir World Foundation Choose Your Own Adventure game.

## Info
Everything is divided into folders that describe the data type for each type of file used in the game. If you are importing a specific type of file, make sure to place it in its proper folder.

## Things To Know
Make sure to work in your own branch only and to start a pull request when you are ready to push into the production branch. Always pull from production before you start working in your branch so everything is up to date to prevent conflicts. If you run into errors please contact me (celestewish aka Lauren R.) before doing anything else.
