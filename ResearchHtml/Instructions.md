# Research Pathway Repository Guidelines

Welcome! This folder is where all your **scripts for the research pathway** will go.  
You can also create **separate folders** for audio, video, or photo assets if you prefer —  
or use the same directories I’m using.

---

## 🧭 Branch Workflow

- All changes will be **merged into the `production` branch**.
- The **`main` branch** will only be used for **new game version releases**.

---

## 🔄 Pull Request Policy

- You may **approve your own pull requests** during meetings.  
- If you need to merge your changes **outside of meeting times**,  
  please **add a comment in the pull request** to notify me, and I’ll review and approve it.

---

## 📚 Communication & Resources

- Use **Notion** to reference current tasks, resources, and updates.  
- If you have **any questions** or need feedback, please **reach out to me directly**.

---

✦ *Thank you for all your hard work!*
